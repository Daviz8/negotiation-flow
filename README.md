
# negotiation-flow

A lightweight, framework-independent JavaScript package for managing offer negotiations, counteroffers, acceptances, rejections, and negotiation-round limits.

Extracted from the core business rules of the StudentShop trade-in negotiation workflow.

## Features

- Create negotiation offers.
- Track negotiation rounds.
- Accept or reject offers.
- Submit counteroffers.
- Enforce a maximum of three negotiation rounds.
- Validate offer and counteroffer prices.
- Return updated sale objects without directly modifying the original sale.
- Works independently of Next.js, Express, MongoDB, or Mongoose.
